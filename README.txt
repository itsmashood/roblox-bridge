Roblox Bridge - AMVerse Public Values Updater

Open README.md for GitHub Desktop installation instructions and important limitations.

This package includes sentient.lua, spray.lua and the original values_elvebredd
along with a new AMVerse public-page extractor and GitHub Actions workflow.
It DOES NOT contain an API key.

Locally tested: parser, schema safety, and value conversion. NOT live verified
against AMVerse on GitHub Actions yet.

The AMVerse owner has shown permission to use an API key, but the supplied chat
does not expressly grant automated website scraping or redistribution. Confirm
those before enabling scheduled scraping.
